# Mongelli Labs: scientific computing and software

Mongelli Labs welcomes scoped projects involving scientific analysis, research software, and reproducible computational workflows.

## Project areas

- **Optics and thin films:** discuss planar optics, OLED research, parameter sweeps, and checks against appropriate reference cases. Models and material inputs need to be reviewed for each intended use.
- **Numerical analysis and reproducibility:** review an existing model or workflow, identify assumptions and limitations, and develop a reproducible analysis or report.
- **Scientific software:** discuss custom scripts, workflow development, and possible licensing of suitable existing tools. Availability, rights, compatibility, and support are confirmed before a quote.
- **Research-document workflows:** discuss local indexing and processing of reviewed native DOCX documents. This is not an OCR or comprehensive privacy-redaction service.

Projects are scoped individually. Deliverables, fees, timing, access, and support are agreed in writing before work begins. This repository contains research prototypes; it is not evidence that a particular model is validated for your application. There is no online checkout or paid download on this page.

## Start a conversation

Use the [Mongelli Labs contact page](https://sites.google.com/u.rochester.edu/mongelli-labs/home/contact) to describe your general objective and desired outcome. Please do not send passwords, credentials, or sensitive files; arrange an appropriate transfer method before sharing project materials.

If that contact page is unavailable, you can [open a GitHub inquiry](https://github.com/gmongell/Mathematica_python_TMM_OLEDPixel/issues/new?template=project-inquiry.md). **GitHub issues are public.** Include only a non-confidential description, and do not post personal contact details, proprietary research, customer data, or credentials.
